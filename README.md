# WeatherPlus Plugin for TrafficMonitor ⛅

Продвинутый погодный плагин для [TrafficMonitor](https://github.com/zhongyang219/TrafficMonitor) с поддержкой прогноза погоды, графических иконок и нескольких погодных провайдеров.

---

## ✨ Возможности

- **Два провайдера погоды на выбор:**
  - **Open-Meteo:** бесплатный, точный, работает сразу «из коробки» без регистрации и без API-ключей.
  - **Яндекс.Погода:** через GraphQL API (требуется ваш API-ключ `X-Yandex-Weather-Key`).
- **Умный поиск городов (Геокодинг):**
  - Поддержка поиска населённых пунктов по названию через OpenStreetMap (Nominatim) и Open-Meteo Geocoding.
- **Информативный дисплей:**
  - Текущая температура и погодная иконка (солнце, дождь, снег, гроза и т.д.).
  - Почасовой прогноз и предупреждение об ожидаемых осадках.
  - Поддержка скролла колесом мыши для просмотра прогноза на следующие часы / завтрашний день.
- **Подробный Tooltip:** расширенная сводка при наведении мыши.
- **Диалог настроек:** удобное окно выбора города, интервала обновления и провайдера.

---

## 📦 Установка

1. Скачайте архив под вашу разрядность системы:
   - **`WeatherPlus-x64.zip`** — для 64-битной версии TrafficMonitor (рекомендуется).
   - **`WeatherPlus-x86.zip`** — для 32-битной версии.
2. Распакуйте содержимое архива в папку `plugins` в каталоге TrafficMonitor:
   ```text
   TrafficMonitor/
   └── plugins/
       └── WeatherPlus.dll
   ```
3. Откройте меню TrafficMonitor → *«Управление плагинами»* → включите **WeatherPlus**.
4. В параметрах плагина укажите ваш город.

---

## 🛠 Сборка из исходников (CMake)

```bash
mkdir build && cd build
cmake .. -A x64
cmake --build . --config Release
```
